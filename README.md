# LocalDrive — Русский

[English version](README.en.md) | [Главная страница](README.md)

LocalDrive — файловый менеджер для устройств в вашей домашней локальной сети. Файлы не отправляются в облако.

## Быстрый запуск (Windows 10/11)

1. Установите Node.js 22 или новее, если он ещё не установлен.
2. Откройте папку проекта и дважды щёлкните `start.bat`. Не запускайте от имени администратора.
3. При первом запуске дождитесь установки зависимостей и сборки; не закрывайте чёрное окно консоли, пока пользуетесь приложением.
4. Откройте адрес, напечатанный в консоли. На телефоне/другом ПК используйте тот же адрес, подключившись к той же частной Wi-Fi/LAN сети.
5. Войдите с именем пользователя `root` и паролем, который зададите локально через `npm run set-password` (введите команду в терминале, открытом в папке проекта). Пароль должен содержать не менее 10 символов; ввод скрыт. Перезапустите сервер после смены пароля.

## Автозапуск

Дважды щёлкните `autostart.bat`, чтобы добавить ярлык в автозагрузку текущего пользователя Windows. Для удаления откройте терминал в папке проекта и выполните `autostart.bat /remove`. Права администратора не нужны.

## Настройки и использование

- Откройте **Settings → Appearance**, чтобы изменить светлую/тёмную тему и цвет интерфейса. Акцентный цвет сохраняется в браузере этого устройства.
- Используйте **Settings → Server** или адрес из консоли для подключения устройств.
- Ограничьте доступные диски через `ALLOWED_ROOTS` в локальном `.env`, если не хотите предоставлять все обнаруженные тома.
- `start.bat` автоматически приостанавливает LocalDrive во время CS2/Dota 2 и запускает снова после выхода из игры.

## Важно: чего НЕ делать

- **Не используйте `1234`**: такой пароль легко угадать. Создайте уникальный пароль длиной от 10 символов.
- Не публикуйте и не отправляйте `.env` или каталог `data/`: там хранятся хэш пароля и секреты сеансов.
- В запросе Windows Firewall разрешайте доступ только для **Private networks** и только в доверенной домашней сети. Не разрешайте **Public networks**.
- Не создавайте перенаправление портов на роутере и не открывайте сервер в интернет. Это HTTP-сервис для доверенной локальной сети.
- Не задавайте `HOST=0.0.0.0`, если не понимаете, что сервер станет слушать все сетевые интерфейсы.
- Не удаляйте/не переименовывайте файлы и папки, если не уверены: удаление файлов в интерфейсе необратимо. Сначала проверьте выбранный путь и подтвердите только нужное действие.
- Не запускайте от администратора: приложению это не требуется.

## Разработка и проверка

`npm run build` проверяет типы и собирает приложение. `npm run smoke-test` выполняет локальный тест операций с файлами; запускайте его только если понимаете, что тест создаёт и удаляет временную папку в Downloads. Подробности и настройки описаны в [README.en.md](README.en.md).
